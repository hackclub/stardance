# Project tiers!

When submitting your hardware project for funding, you'll have to pick 1 of 4 tiers! Each tier has a different complexity & polish bar and limits how much funding you can get.

All hardware projects still need to be shipped in order to be approved! You can find out more at [Shipping your hardware project](/resources/shipping-hardware)

_your reviewer has discretion to move your project up or down a tier! if it doesn't cover all the funding you need, you'll be asked to make changes_

---

### B tier, up to $25 in funding

This is the most basic tier! It's for basic projects like macropads, PCB Business cards, and simple 3D prints!

![image](https://cdn.hackclub.com/019faeb1-8568-7e62-98b1-2ccab55c0764/btierup.png)

---

### A tier, up to $120 in funding

This is the next tier up! This is for more complex projects like devboards, keyboards, and basic gadgets!

Some examples are:

- [Hack Club's Orpheus Pico 2!](https://github.com/hackclub/orpheus-pico)
- [@hephaestushex's HexBoard keyboard!](https://github.com/hephaestushex/HexBoard)
- [@Dylan's Kitt battlebot!](https://github.com/DylM0nster22/1lb-vertical-spinner)

![image](https://cdn.hackclub.com/019faf15-6a0e-7954-8ff5-31c3b2326b13/atuer.png)

---

### S tier, up to $200 in funding

This tier is for more complex designs! Complex PCBs, high-polish devices, and more!

Some examples are:

- [@Tomas' Lora Travel Buddy](https://github.com/Tomas-Kuchta-FPV/Travel-Buddy)
- [@Clém's AngstromIO devboard](<>)
- [@vuk's Cuber Rubik's cube solver](https://github.com/vuktacic/cuber)

![image](https://cdn.hackclub.com/019faf1f-8440-74af-b982-f7bee330ab97/stier2.png)

---

### X tier, Up to $600 USD in funding; case-by-case situation!

Have a big idea you want to work on? This is the place! This is for projects like:

- A new 3D printer/CNC/etc design!
- A rocket!
- Complex 4-6 layer PCBs
- An ultra polished project, i.e something you could sell as a product!

Here's some example projects that would be great X tier projects:

- [@Allen D's Ender-X4](https://github.com/ading2210/ender-x4)
- [@koeg's Meko MP3 Player](https://github.com/KOEGlike/meko)
- [@Kai Peireira's Cheetah MX4](https://github.com/KaiPereira/Cheetah-MX4-Mini/tree/master)

![image](https://cdn.hackclub.com/019faf1f-9b5a-7a1c-8351-6c2bbf2c67e1/xtier.png)

_If this is your first time creating a hardware project, it's strongly recommended you work on a project from another tier instead!_
