# Development Community Seed System

This system generates a random, interconnected data of users, projects, etc to help developers test the application with live data.

## Usage

To generate the community data:

```bash
bin/rails seed:community
```

### Generation and Cleanup
Every time you run it, it will:
1.  **protect the admin user** (`kartikey@hackclub.com`) and any projects they are a member of.
2.  **wipe existing community data** generated by previous runs.
3.  **generate a fresh set of records** based on the current configuration.

## Configuration

You can customize the generated data in `db/development_seed/config.rb`:

- `USER_COUNT`: number of users to create.
- `PROJECTS_PER_USER`: number of projects each user.
- `MIN/MAX_DEVLOGS_PER_PROJECT`: range of progress updates per project.
- `MIN/MAX_REPOSTS_PER_POST`: range of reposts per devlog.
- `RANDOM_SEED`: change this to generate a different sequence of names and titles.

## Architecture

The system is organized into modular generators:
- `Users`: names.
- `Projects`: generic titles.
- `Devlogs`: generic devlogs for projects.
- `Comments/Likes/Reposts`: social engagement layer.
- `Stardust`: Financial history (earnings and spendings) .
- `Summary`: report of the generated data.

## Extending the System

To add a new generator:
1.  Create a new class in `db/development_seed/`.
2.  Add its constants to `config.rb`.
3.  Register it in `db/development_seed/runner.rb`.
